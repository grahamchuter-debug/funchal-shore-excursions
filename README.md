# Funchal Shore Excursions

World 2.0 destination site for [funchalshoreexcursions.com](https://funchalshoreexcursions.com) — cruise shore excursions, independent advice and Madeira island planning from Funchal.

## Commands

```bash
npm install
npm run download:images   # Wikimedia masters + optimize
npm run dev
npm run build
npm run qa:world2         # World 2.0 audit with build
npm run pages:deploy      # Cloudflare Pages
```

## Stack

Next.js static export · Tailwind 4 · Cloudflare Pages · World 2.0 image pipeline (AVIF/WebP/JPEG)
